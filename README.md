# Poppy Playtime Web 3D Prototype

Poppy Playtime の雰囲気を参考にした、ブラウザ向け 3D プロトタイプです。

## できること
- WASD + マウスで探索
- Shift ダッシュ
- Space ジャンプ
- クリックで GrabPack 的なオブジェクト掴み/離し

## 起動方法
```bash
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173` を開いてください。
